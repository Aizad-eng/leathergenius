# Zipper intro (`LGFx.zipper`)

A closed leather jacket front covers the page (or one block). After a 1.2 s beat, or as soon as the visitor drags the pull, scrolls, presses a key or taps, the slider runs down, the teeth part, and the two panels roll back (lining showing) to reveal the page. Plays once per browser session, never shows for `prefers-reduced-motion`, and gets out of the way if WebGL or the textures fail.

Demo: `/lab/zipper/` (controls, `?t=0.4` freezes a frame, `?color=espresso&metal=nickel`, `?where=hero`).
Production wiring exactly as below: `/lab/zipper/home.html`.

## Drop-in (whole screen, homepage)

1. In `<head>`, before the stylesheets (decides before first paint, so the page never flashes):

```html
<script>try{if(!sessionStorage.getItem('lg-zipper-done')&&!matchMedia('(prefers-reduced-motion: reduce)').matches){document.documentElement.classList.add('lgz-pending');setTimeout(function(){document.documentElement.classList.remove('lgz-pending')},2600)}}catch(e){}</script>
<link rel="stylesheet" href="/assets/fx/zipper/module.css">
<link rel="modulepreload" href="/assets/vendor/three/three.module.min.js">
```

2. At the end of `<body>`:

```html
<script type="module">
  import '/assets/fx/zipper/module.js';
  LGFx.zipper.mount(document.body, { color: 'oxblood', metal: 'brass' });
</script>
```

`lgz-pending` shows `poster.webp` (the closed jacket, oxblood + brass) until the first WebGL frame. If you pick espresso or nickel, re-render the poster from `/lab/zipper/?t=0&poster=1&color=espresso` or drop the boot line (the page will show for a moment before the jacket).

## Hero block only

```html
<script type="module">
  import '/assets/fx/zipper/module.js';
  LGFx.zipper.mount(document.querySelector('.hero'), { color: 'espresso', metal: 'nickel' });
</script>
```

The overlay is absolutely positioned inside the element (it sets `position: relative` if the element is static). Skip the boot line in this mode, it covers the whole screen.

## API

- `LGFx.zipper.mount(el, { color: 'oxblood'|'espresso', metal: 'brass'|'nickel', auto: true, delay: 1200, force: false })` returns a promise of the instance, or `null` when it decided not to play (already played this session, reduced motion, WebGL or textures failed, or assets took longer than 1.6 s). `force: true` ignores those checks (lab use).
- `LGFx.zipper.seek(t)` freezes the animation at `t` in 0..1 (0 closed, ~0.56 slider at the bottom, 1 gone). For frame grabs.
- `LGFx.zipper.play()`, `LGFx.zipper.skip()`.
- Fires `lgzipper:done` (bubbles, `detail.skipped`) on the element when finished. Sets `sessionStorage['lg-zipper-done'] = '1'`.

Timing: auto-play starts 1.2 s after mount (counted from mount, so slow loads do not add to it), the run lasts 1.85 s, and a hard stop forces it to finish by about 3 s even if the visitor holds the pull. Esc or the Skip button removes it at once.
